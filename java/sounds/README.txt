Voice clips for the helper and the ghost.

On the first run the game generates them with the computer's text-to-speech
and stores them in the generated_v2 folder.
To use your own voice, record WAV files with these names (they replace the generated ones):

  forward.wav  backward.wav  left.wav  right.wav
  start.wav  poisoned.wav  hide.wav  passed.wav  caught.wav  won.wav  lost.wav

Delete the generated_v2 folder to make the game generate all clips again.
